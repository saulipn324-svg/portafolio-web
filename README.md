# Portafolio de Saul Ramos Sanchez

Portafolio en español con React, TypeScript y Tailwind CSS, generado con Sites y Vinext.

## Desarrollo

Requiere Node.js 24 LTS y npm.

```sh
npm ci
npm run dev
```

Abre la dirección que indica la terminal. Para producción: `npm run build`.

## Personalización

- `app/page.tsx`: perfil, tecnologías, experiencia, proyectos y contacto.
- `app/globals.css`: colores, tipografía y diseño adaptable.
- `app/layout.tsx`: idioma, título y metadatos. Cambiar metadataBase si cambia el dominio.
- `public/`: icono y tarjeta para compartir.

La experiencia y los contactos se basan en el CV proporcionado. Issueflow ya tiene una demo y documentación; los otros dos proyectos personales siguen planificados. React, TypeScript y Tailwind se utilizan en este portafolio; no se presentan como experiencia profesional previa.
